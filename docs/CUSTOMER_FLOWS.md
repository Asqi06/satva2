# Customer Flows

## Discover

Home (hero, featured categories, new arrivals, best sellers, offers, collections, social proof, newsletter) → shop/category/search → filter/sort → product detail → related/recently-viewed.

## Cart → Checkout

Add to cart (variant/qty validated) → cart drawer/page → coupon → login (guest cart merges) → address → delivery → Razorpay → verify → confirmation → email.

## Post-purchase

`/account` → overview → orders → detail/timeline → cancel (if eligible) → review purchased product (verified badge) → wishlist/addresses/profile management.

## Guest Path

Browse + guest cart (localStorage) fully; login required before payment (per AUTH.md decision). Wishlist requires auth.
