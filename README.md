# SatvaStones

D2C jewellery e-commerce platform — Korean, Western, Gen-Z, Pinterest-inspired aesthetic jewellery for Indian customers.

## Stack

- Next.js + React + TypeScript + Tailwind CSS
- MongoDB Atlas + Mongoose
- Auth.js + Google OAuth
- Razorpay, Cloudinary, Resend, Vercel
- Zod + React Hook Form; Vitest + Playwright

## Development

Install: `npm install`

Run: `npm run dev`

Typecheck: `npm run typecheck`

Lint: `npm run lint`

Test: `npm test`

Build: `npm run build`
